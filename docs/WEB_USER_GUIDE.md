# snapatch 웹 이용 안내

**버전:** v1.02 · **대상:** 브라우저에서 snapatch 웹앱을 쓰는 이용자

별도 프로그램 설치나 **API 키 입력 없이** 바로 사용할 수 있습니다.  
(서비스 운영자가 서버에 필요한 설정을 미리 해 두었습니다.)

> **면책:** AI·시세 정보는 참고용입니다. 투자 판단과 손익 책임은 이용자 본인에게 있습니다.

---

## 1. 시작하기

1. 웹 주소에 접속합니다.
2. 왼쪽 **사이드바**에서 원하는 기능을 선택합니다.
3. 화면 안내에 따라 입력 후 **생성 / 분석** 버튼을 누릅니다.


| 사이드바 표시 | 의미 |
|---------------|------|
| **ON** (녹색) | 지금 바로 사용 가능 |
| **KEY** (노란색) | 서비스 준비 중 — 잠시 후 다시 시도하거나 운영자에게 문의 |

---

## 2. 화면 구성

| 메뉴 | 설명 |
|------|------|
| **홈** | 4개 기능 요약 카드 |
| **breaker** | 시황 속보 생성 |
| **diver** | 키워드 뉴스 분석 |
| **dejavu** | 과거 유사 패턴 |
| **match** | 유사 종목 검색 |
| **사용 설명서** | 이 문서 (사이드바 **맨 아래**) |

- 우측 상단 **달/해** 아이콘: 다크 · 라이트 테마
- 결과는 **화면에서 확인**하고, **다운로드 버튼**으로 PC에 저장하세요.

---

## 3. 결과 저장 (중요)

웹 서버에는 **`outputs` 폴더가 없습니다.**  
생성된 리포트·표·차트는 **서버에 영구 저장되지 않으며**, 브라우저를 닫거나 앱이 재시작되면 사라질 수 있습니다.

| 기능 | 저장 방법 |
|------|-----------|
| **breaker** | **마크다운 다운로드** 버튼 |
| **diver** | **Markdown 다운로드** 버튼 |
| **dejavu** | 차트는 화면 캡처, **표·결과문서 다운로드** expander |
| **match** | 결과 표 · 유사도 차트 화면 확인 (필요 시 캡처) |

분석 직후 **반드시 다운로드**해 두는 것을 권장합니다.

---

## 4. breaker — 시황 속보

**무엇을 하나요?**  
코스피·코스닥·해외 지수 등 **실측 시세**를 반영한 한국어 시황 리포트를 AI가 작성합니다.

**사용 방법**

1. 사이드바 **breaker** 선택
2. **생성 모드** 선택
   - **빠름** — 약 5~10초 (뉴스 검색 생략)
   - **정확** — 약 20~40초 (Google 검색 포함, 뉴스 인용 품질↑)
3. **속보 생성** 클릭
4. 생성 중 **실측 시세** 캡션 확인 (`[naver]`, `[yahoo]` 등)
5. 리포트 확인 → **마크다운 다운로드**

**팁**

- 지수 숫자는 실측 API 기준입니다. 뉴스 헤드라인과 다를 수 있습니다.
- `실측 시세 조회 실패` 경고가 뜨면 잠시 후 다시 시도해 보세요.

---

## 5. diver — 키워드 뉴스 분석

**무엇을 하나요?**  
키워드 관련 네이버 뉴스를 모아 AI 투자 리서치 형식으로 분석합니다.

**사용 방법**

1. **diver** 메뉴
2. **검색 키워드** 입력 (예: `삼성전자`, `2차전지`, `금리인하`)
3. **목표 기사 수** · **최대 검색 기간(일)** 조절
4. **원문 생략** — 켜면 더 빠름 (제목·요약 위주)
5. **분석** 클릭
6. 결과 확인 → **Markdown 다운로드**

**팁**

- 처음에는 목표 기사 **5건**, 원문 생략 **켜기**를 권장합니다.
- 분석에 1~2분 걸릴 수 있습니다.

---

## 6. dejavu — 과거 유사 패턴

**무엇을 하나요?**  
선택한 종목의 최근 주가 패턴과 비슷했던 **과거 구간**을 찾고, 그 이후 수익률을 요약합니다.

**사용 방법**

1. **dejavu** 메뉴
2. **종목 코드** (예: `005930`), **관찰 거래일**, **트랙** 등 설정
3. **패턴 분석** 클릭
4. 차트·표 확인
5. **표·결과문서 다운로드** expander에서 CSV / MD / TXT 받기

**팁**

- 종목 코드는 6자리 숫자 (KOSPI/KOSDAQ).
- **활성 트랙**은 처음에는 기본값 그대로 두어도 됩니다.

---

## 7. match — 유사 종목 검색

**무엇을 하나요?**  
기준 종목의 최근 가격 흐름과 **닮은 다른 종목**을 검색합니다.

**사용 방법**

1. **match** 메뉴
2. **기준 종목**, **패턴 기간**, **후보 종목 수** 등 입력
3. (선택) KRX ID/PW — 데이터 조회가 느리거나 실패할 때만
4. **유사 종목 검색** 실행
5. 결과 표 · 차트 확인

## 8. 자주 묻는 질문

### Q. API 키를 어디에 입력하나요?

**입력하지 않습니다.** 웹 이용자는 키 설정이 필요 없습니다.

### Q. 예전에 만든 리포트를 다시 볼 수 있나요?

웹 서버에 영구 보관되지 않습니다. 분석 직후 **다운로드**해 PC에 저장하세요.

### Q. breaker 지수가 이상해요

**실측 시세** 캡션이 표시됐는지 확인하세요. 실패 경고가 있으면 재시도하세요.

### Q. diver / breaker가 실패해요

잠시 후 다시 시도하거나, diver는 **원문 생략**·기사 수 줄이기를 시도하세요.

### Q. 화면이 예전 버전 같아요

브라우저 **새로고침**(Ctrl+F5 / Cmd+Shift+R)을 해 보세요.
