# Release Notes

릴리스 노트는 **[CHANGELOG.md](../CHANGELOG.md)** 로 통합되었습니다.

요즘 오픈소스에서는 **Release Notes** 대신 **Changelog**(`CHANGELOG.md`)를 쓰는 경우가 많습니다.
[Keep a Changelog](https://keepachangelog.com/) 형식을 따릅니다.

| 문서 | 용도 |
|------|------|
| [CHANGELOG.md](../CHANGELOG.md) | 사용자·배포용 변경 이력 (버전별 Added/Changed/Fixed) |
| [USER_GUIDE.md](USER_GUIDE.md) | **로컬 · CLI** 사용 설명서 |
| [WEB_USER_GUIDE.md](WEB_USER_GUIDE.md) | **웹 이용자** 안내 (API 키·설치 불필요) |
| [DEVELOPMENT_NOTES.md](DEVELOPMENT_NOTES.md) | 개발자용 배경·의사결정·버전 메모 |

버전을 올릴 때는 `hub/project_info.py`의 `VERSION`과 위 두 문서를 함께 갱신하세요.
